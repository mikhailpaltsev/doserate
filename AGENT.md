# AGENT.md — обработка данных


## 0. Цель и образ результата
Оценка коэффициента полувыведения препарата и подбор трёх лучших моделей для интерполяции результата.

В конце проекта только:
- `result/.xlxs` - столбцы `№ пациента, [коэффициенты полувыведения моделей №N], [метрики сходства данных и модели]`

## 1. Данные и материалы
- `data/*.docx` — протоколы и акты в формате .docx.
- `data/*.xlxs` - таблица формата .xlxs актуального журнала. В ней разные листы, в них либо в каких-то из столбцов X или W лежат данные аргументов (время. разделитель - пробел. десятичный - разделитель), а в столбцах дальше (название МАЭД(3) №N)значения мощности дозы соответстенно для этих аргументов по три измерения на временную точку.


## 2. Как работать
- Нужно выбрать три лучшие математические модели для аппроксимации данных, полученных из входных данных.
- Не работать с пациентами, у которых не заполнена данная информация.
- Не работать с пациентами, у которых не совпадает количество временных точек и измерений (с учетом тройного снятия данных)
- Эталон считывания данных представлен в `data/data_example.txt` в виде реальных данных из таблицы. Проверь с их помощью сбор данных
- Номер пациента всегда указан в столбце `А`
- Выбери на свое усмотрение способ отбора лучшей кривой для апроксимации

## 3. Чем пользоваться
- Используй библиотеки pandas, numpy, scipy для обработки данных.
